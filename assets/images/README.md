# assets/images/

Reservada para **imagens usadas na interface** do sistema — fotos
ilustrativas, banners, ou imagens de apoio que não sejam o logo nem
ícones de sistema.

## Exemplos de uso futuro
- Uma imagem ilustrativa na tela inicial (ex: foto do chão de fábrica).
- Capturas de tela do sistema, usadas na documentação em `docs/`.
- Imagens de exemplo/modelo para o campo de evidência fotográfica
  (útil em treinamentos, para mostrar como uma boa foto de evidência
  deve ser tirada).

## Importante
Fotos de evidência que os **usuários** anexam durante o uso normal do
sistema **não** são salvas aqui — elas ficam apenas na memória do
navegador durante o preenchimento e são incorporadas diretamente ao PDF
gerado. Esta pasta é só para imagens estáticas que fazem parte do
próprio projeto.
